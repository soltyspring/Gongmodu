## 배포

[BlueCL 설치·검증·복구 안내](../deploy/bluecl/README.md)를 참고합니다. 서버 전용 DART 키는 공개 폴더나 Git에 넣지 않습니다. 서버 소스는 `/home/solty/dev/gongmodu/current`, 서비스는 `gongmodu.service`, 수신 주소는 `127.0.0.1:18824`입니다.

공개 API 앞단의 보안 정책으로 Python 기본 User-Agent 같은 요청은 403이 발생할 수 있습니다. 정상 브라우저 요청과 토스 origin을 넣은 요청으로 200 및 CORS를 확인했습니다. 토스 실기기의 실제 WebView에서도 반드시 확인해야 합니다.
