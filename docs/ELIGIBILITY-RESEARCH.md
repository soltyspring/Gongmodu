# 공모주 일정 조회 앱 입점 가능성 추가 조사

확인일: 2026-10-25 (한국 시간)

## 수정한 판단

**공모주 일정 조회만으로 무조건 입점 불가라고 단정할 근거는 부족해요.** 공식 정책의 금융상품 관련 제한은 존재하지만, 유사 앱의 운영사 소개와 주식 관련 서비스의 소명 후 승인 경험도 확인했어요. 반대로 ‘일정 조회라면 자동 허용’이라는 공식 답변도 확인하지 못했어요. 현재 결론은 **일정 정보 조회라는 실제 기능 범위를 제시해 개별 확인할 사안**이에요.

기존 문서는 공식 정책에 따른 위험을 강조했으나, 실무 승인 경험과 유사 사례 확인이 부족했어요. 입점 불가 가능성이 높다고 읽힐 수 있는 판단을 위 내용으로 정정해요.

## 1. 공식 정책에서 확인한 것

[서비스 오픈 정책 §3-5, §3-6](https://developers-apps-in-toss.toss.im/intro/guide.md)는 증권 등 금융상품 관련 서비스와 투자 자문·특정 종목 추천 등에 제한을 두고 있어요. 다만 공개 문구만으로 공시의 날짜를 보여주는 일정 서비스가 금융상품 판매·중개 등과 어떻게 구분되는지 확정할 수 없어요. 일정 조회 전용 서비스의 허용/불허를 명시한 공식 공개 답변은 이번 조사에서 찾지 못했어요.

따라서 거래 기능이 없다는 이유만으로 승인을 보장하거나, 주식이라는 주제만으로 최종 불가라고 단정하는 것은 모두 피해야 해요.

## 2. 공식 커뮤니티의 심사 경험과 운영진 답변

### 주식 관련 서비스: 반려 후 소명·승인 경험

2026-05-20 [‘수정사항이 반려됐어요’](https://techchat-apps-in-toss.toss.im/t/topic/3865)에서:

- 질문자는 ‘차트 전문가’ 앱의 반려 이유를 문의했어요.
- 다른 개발자 `hslab`은 자신도 주식 관련 서비스를 출시할 때 같은 반려를 받았지만, 채널톡으로 정책에 저촉되지 않음을 소명해 승인받았다고 밝혔어요.
- 운영진 `Dylan`은 만들려는 서비스의 내용을 확인하기 위해 채널톡으로 문의해 달라고 답했어요.

**증거 구분:** 소명 후 승인 경험은 개발자 본인의 진술이에요. 운영진이 모든 주식·일정 서비스를 허용한다고 선언한 것은 아니에요. 다만 개별 서비스의 내용을 확인하는 심사 절차가 있음을 뒷받침해요.

### 최근 모의 매매 문의

2026-10-08 [‘토스증권 Open API의 캔들 데이터 사용 가능 여부 문의’](https://techchat-apps-in-toss.toss.im/t/open-api/4941)는 실물 자산·주문·추천이 없는 모의 매매 앱의 입점 여부를 물었고, 운영진은 10월 12일 정책 사항은 채널톡으로 문의하라고 안내했어요. 일정 조회와 기능이 다른 사례이므로 승인/불허 선례로 삼지 않았어요.

### ‘금융 캘린더’ 문의의 의미

2026-08-16 [‘금융 캘린더 기능을 추가하고 싶습니다’](https://techchat-apps-in-toss.toss.im/t/topic/4618)의 운영진 답변은 토스뱅크 금융 캘린더 기능을 SDK로 제공하지 않는다는 내용이에요. 자체 일정 조회 앱의 입점이 금지된다는 답변으로 해석하면 안 돼요.

## 3. 찾은 유사 서비스

| 서비스 | 공개 자료에서 확인한 내용 | 확인 수준 / 남은 점 |
| --- | --- | --- |
| 공모주 미리보기 — 미니랩소프트 | [운영사 홈페이지](https://rrecommend.com/)에서 DART 증권신고서 기반 청약 일정 앱으로 소개. ‘모두 토스 앱 안에서 바로 열리는 미니앱’ 목록에 포함하고, 2026-10-13 기준 신규 이용자 1,455명을 기재 | 운영사 본인의 직접 소개와 이용 수치. 토스 공식 목록의 현재 상태·실행 링크·승인 조건은 독립 확인하지 못함 |
| 주식 광장 | [서비스 홈페이지](https://stocksquare.co.kr/)에 공모주 일정·청약 예정·상장 예정 섹션이 있고, 토스 미니앱 버전을 별도로 설명 | 서비스 자체 안내. 일반 웹 버전 전체 기능이 토스에서도 동일하게 제공되는지, 현재 입점·실행 상태인지는 미확인 |

첫 번째는 만들고 있는 앱과 직접 비교할 만한 사례예요. 두 번째는 더 넓은 투자 정보 서비스의 보조 사례예요. 운영사 소개를 토스의 현재 승인 보증으로 바꾸어 말하지 않았어요. 이 둘의 과거 승인 시기·계약·데이터 요건을 확인하지 못했으므로 우리 앱이 똑같이 승인된다는 결론도 내리지 않아요.

## 4. 우리 앱에 적용할 다음 단계

현재 구현한 일정·검색·관심 저장·파일 내보내기 범위를 구체적으로 제시하고, ‘공시 기반 사실·날짜의 열람’으로 심사 범위를 확인하는 것이 적절해요. 이는 공식 승인을 대신하는 해석이 아니에요.

- 청약 신청/주문/매매/가입·계좌 개설·금융상품 중개를 제공하지 않음을 설명해요.
- 특정 종목 추천·순위화·수익 예측·개인화 투자 판단을 제공하지 않음을 설명해요.
- 캘린더의 원본 출처, 데이터 갱신·정정 방식, 표시 필드를 함께 제시해요.
- 유사 사례 ‘공모주 미리보기’를 언급하되 현재 동일 기준이 적용되는지 질문해요.
- 추가 조사 당시에는 Google Calendar 기반이었지만, 이후 사용자 결정에 따라 DART 증권신고서 기반으로 교체했고 실 API 수집도 검증했어요. [현재 데이터 구조](DART-DATA.md)를 참고해요. 이 전환이 입점 승인을 보장하지는 않아요.

문의는 작성만 했고 발송하지 않았어요. 앱인토스 콘솔의 채널톡에 서비스 설명과 화면을 첨부하면 돼요. 문의 초안은 [출시 준비 문서](RELEASE.md)에 반영했어요.
