## 2026-10-28 사용자가 전달한 앱인토스 가이드 반영

- 버튼만 읽어도 이동 대상을 예상할 수 있도록 기업 상세 CTA를 ‘기업 정보 보기’로 바꿨습니다. 기업 소개와 재무정보는 사용자가 누른 뒤에만 열리고, 닫기·일정으로 돌아가기·네이티브 뒤로 가기 경로를 유지합니다.
- 공모두 이름·로고·녹색 브랜드와 3개 플로팅 탭을 유지합니다. SDK 3.x 설정의 `brand.primaryColor`는 `#087f70`이고 화면을 막는 첫 진입 시트·광고·알림 동의를 추가하지 않았습니다.
- 외부 자료 링크에는 ‘IRGO에서 기업 소개 자료 보기’라고 목적지를 표시하고, 출처 호스트·회사명·자료 종류를 확인합니다. 외부 페이지는 기기의 외부 URL 열기 동작으로 연결합니다.
- 기업 설명의 원문 발췌는 임의로 말투를 바꿔 의미를 바꾸지 않으며 앱의 안내와 CTA에는 해요체·직접적인 행동 표현을 사용합니다. 모르는 숫자를 0이나 흑자로 대신하지 않습니다.
- 390px 모바일과 1440px 데스크톱에서 CTA, 기업 요약·당기순이익·출처 링크 및 복귀 흐름을 검증했습니다. 600×600 로고와 라이트·다크 시인성의 콘솔 재심사는 이번 작업에 포함하지 않았습니다.

## 바꾼 흐름

홈은 가장 가까운 청약을 먼저 보여주고 달력과 다가오는 일정이 이어집니다. 큰 소개 문구와 내보내기는 다시 추가하지 않았습니다. 목록의 날짜를 별도 줄로 보여줘 증권사 이름 때문에 날짜가 말줄임되지 않게 했습니다.

상세는 회사·청약 날짜, 청약/환불/상장 요약, 청약 정보, 필요할 때 펼치는 공시 근거 순서입니다. 관심 저장은 TDS의 큰 버튼으로, 공시 원문은 외부 페이지임을 알리는 링크로 제공합니다. 상장일 미확인은 확인 전으로 표시하며 날짜를 만들어내지 않습니다.

관심 아이콘의 터치 영역은 44px, 목록 보조 글씨는 모바일 13px로 조정했습니다. 네이티브 상단바가 있는 토스에서는 중복 웹 헤더를 숨기는 기존 동작을 유지합니다.

상세 주소로 직접 들어온 경우 수집 데이터 응답을 기다리는 동안 로딩을 표시합니다. 응답 전 잠깐 나타나던 ‘일정을 찾을 수 없어요’ 문구를 없애고 지연 응답 브라우저 검사로 확인했습니다.
