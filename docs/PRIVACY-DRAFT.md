# 공모두 개인정보 처리방침 초안 — 게시 전 검토 필요

이 문서는 현재 코드와 서버 설정을 바탕으로 정리한 초안입니다. 개인정보 처리 실태와 운영 정책을 확인한 뒤 게시해야 합니다.

## 운영자와 문의
블루씨엘 / bluecl@bluecl.cloud

## 현재 확인한 처리
- 관심 일정과 청약 준비 기록은 앱이 기기의 로컬 저장소에 보관합니다. 기기 데이터 삭제 시 해당 기록이 삭제될 수 있습니다.
- 일정 조회 요청은 bluecl.cloud의 서버를 거칩니다. 해당 서버의 Nginx 접속 로그 형식에는 IP 주소, 접속 시각, 요청 방식과 경로, 응답 상태, 응답 크기, 처리 시간, 사용자 에이전트가 포함됩니다. 현재 설정은 일 단위 순환, 13개 보관 및 최대 14일 기준 삭제입니다. 실제 운용과 백업의 보관 기간도 확인이 필요합니다.
- 문의 이메일을 보내면 답변을 위해 발신 이메일 주소와 문의 내용이 처리될 수 있습니다. 처리 목적, 보관 기간, 삭제 절차와 메일 서비스 수탁 관계는 확정이 필요합니다.
- 토스 및 네트워크 제공자의 처리 범위, 국외 이전 및 위탁 여부는 실제 계약과 설정을 확인해야 합니다.

## 이용자의 요청
개인정보 관련 문의와 열람·정정·삭제 등 요청은 bluecl@bluecl.cloud로 접수하는 방안을 검토합니다. 담당자, 처리 절차 및 안전조치·시행일을 운영자가 확인해 채워야 합니다.
